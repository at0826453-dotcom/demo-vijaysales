# cards-video-reel

Custom **cards** block. Purpose: scroller of portrait short-video thumbnails with a play icon and view count.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per video; cell 1: thumbnail image; cell 2: video link and optional view count / caption.
