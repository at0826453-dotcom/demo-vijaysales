# tabs-product

Custom **tabs** block. Purpose: pill-shaped category tabs, each panel holding a scrolling carousel of bordered product cards; optional band background artwork and View All link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab; cell 1: tab label; cell 2: a bulleted list of product cards, each list item holding the product image, linked name and price lines (separated by line breaks). Optional extra rows: a single cell with only picture(s) = band background (desktop, then mobile); a single cell with only a link = View All action shown beside the tabs.
