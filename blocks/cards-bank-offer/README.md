# cards-bank-offer

Custom **cards** block. Purpose: auto-scrolling strip of compact bordered bank-offer chips (logo left, offer text right).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per offer; cell 1: bank logo image; cell 2: offer text and the T&C note as paragraphs. Author each unique offer once; the block duplicates items itself for the looping animation.
