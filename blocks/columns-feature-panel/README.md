# columns-feature-panel

Custom **columns** block. Purpose: one row of three differently designed rounded panels (partners, loyalty sign-up, extended warranty).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, three cells; each cell: badge/logo image, heading, text, CTA link and optional product image. A cell holding only an image becomes an image panel.

## Supported variations

No variations.
