# cards-product-tile

Custom **cards** block. Purpose: horizontal carousel of large grey-background product tiles (image, name, rating, price), usually placed beside an intro in a split section.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per product; cell 1: product image; cell 2: product name link, rating, price (strike the MRP with del) and discount as paragraphs.

## Supported variations

No variations.
