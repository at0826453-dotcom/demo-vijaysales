# cards-category

Custom **cards** block. Purpose: single scrolling row of borderless category tiles: product cut-out image above a centred label link, with arrow controls.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per category; cell 1: category image; cell 2: category label as a link to the listing page (the image becomes clickable with the same link).
