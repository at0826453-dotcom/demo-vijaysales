# cards-promo-tile

Custom **cards** block. Purpose: two large rounded image-only promotional tiles side by side, stacking on mobile.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile; cell 1: promo image; cell 2 (optional): link to the promo destination (a link whose text is only the URL is folded into the image).

## Supported variations

No variations.
