# cards-brand-logo

Custom **cards** block. Purpose: centred row of circular light-grey brand logo tiles, each linking to the brand store.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per brand; cell 1: brand logo image; cell 2: link to the brand page (a link whose text is only the URL is folded into the logo).

No variations.
