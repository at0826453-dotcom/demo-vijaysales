# carousel-hero

Custom **carousel** block. Purpose: full-width promotional banner slider; each slide is a linked banner image with its copy baked into the artwork, with prev/next arrows, dot pagination and autoplay.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide; cell 1: desktop banner image, optionally followed by a mobile banner image (first picture = desktop, second = mobile); cell 2: the slide link (or optional heading, text and CTA when the copy is not baked into the image).

## Supported variations

No variations.
